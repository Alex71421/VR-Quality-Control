# Система выходного контроля качества шлемов VR — процедурная реализация

Язык: Python 3.14.8. Используется только стандартная библиотека (json, sys).

## Сборка

Отдельная сборка не требуется.

## Запуск

```
cd src
python main.py data.json
```

## Входные данные

Файл `data.json` содержит пять списков, соответствующих сущностям логической модели:
`models` (модели шлемов), `check_items` (пункты проверки), `helmets` (шлемы),
`acts` (акты контроля), `results` (результаты проверки). Пример записи акта:

```json
{"act_id": 2, "serial": "VR1-0002", "date": "2026-10-21", "inspector": "Петров И. С.", "decision": "брак"}
```

## Что делает программа

1. Регистрирует новый шлем и заводит на него акт контроля.
2. Вводит результаты проверок по пунктам.
3. Выносит решение «годен» или «брак» (алгоритм 1) и печатает протокол.
4. Считает количество брака по моделям за период (алгоритм 2).
