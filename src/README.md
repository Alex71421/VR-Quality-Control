# Система выходного контроля качества шлемов VR — процедурная реализация
Язык: Python 3.14.8. Используется только стандартная библиотека (json, sys).

## Сборка
Отдельная сборка не требуется.

## Запуск
```
cd src
python main.py data.json
```

## Входные данные
Файл `data.json` содержит шесть списков, соответствующих сущностям логической модели:
`models` (модели шлемов), `check_items` (пункты проверки), `helmets` (шлемы),
`employees` (сотрудники), `acts` (акты контроля), `results` (результаты проверки).
Поле `inspector_id` в акте ссылается на `employee_id` в списке сотрудников.

Пример записи акта:
```json
{"act_id": 2, "serial": "VR1-0002", "date": "2026-10-21", "inspector_id": 1, "decision": "брак"}
```

## Что делает программа
1. Регистрирует новый шлем и заводит на него акт контроля.
2. Вводит результаты проверок по пунктам.
3. Выносит решение «годен» или «брак» (алгоритм 1) и печатает протокол.
4. Считает количество брака по моделям за период (алгоритм 2).

## Пример вывода
```
Протокол контроля, акт 5
Шлем: VR1-0003  дата:  2026-10-25  контролер: Петров И. С.
Внешний осмотр корпуса и линз - пройден
Комплектность - пройден
Дисплеи: битые пиксели - пройден
Оптика: межзрачковое расстояние - Не пройден: Нечёткость изображения по краям
Решение: брак

Брак по моделям за 2026-10-20 - 2026-10-31:
  VR-One - 2
  VR-One Pro - 1
```
