# Система выходного контроля качества шлемов VR — объектно-ориентированная реализация
Программа написана на Java 11. Сборка и запуск проверены на JDK 11.0.17 и Maven 3.9.16. Для чтения JSON используется Gson 2.13.2.

## Сборка
Выполните команду из папки, в которой лежит `pom.xml`.

```powershell
mvn compile
```

## Запуск
При запуске из репозитория используется общий файл `../data.json`.

```powershell
mvn exec:java "-Dexec.mainClass=vrqualitycontrol.Main" "-Dexec.args=../data.json"
```

В архиве КТ3 файл `data.json` лежит рядом с `pom.xml`.

```powershell
mvn exec:java "-Dexec.mainClass=vrqualitycontrol.Main" "-Dexec.args=data.json"
```

## Входные данные
Файл `data.json` содержит модели шлемов, пункты проверки, шлемы, сотрудников, акты контроля и результаты проверок. Например, в списке `acts` есть запись об акте контроля.

```json
{"act_id": 2, "serial": "VR1-0002", "date": "2026-10-21", "inspector_id": 1, "decision": "брак"}
```
